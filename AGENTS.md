# Règles agents

- Lire SPEC.md avant toute modification.
- Ne jamais casser une fonctionnalité déjà validée.
- Travailler par petites tâches atomiques.
- Créer une branche Git par tâche.
- Écrire ou mettre à jour les tests pour chaque fonctionnalité.
- Documenter chaque décision dans agents/reports/.
- Ne jamais supprimer de code sans justification.
- Tout changement doit être validé par tests.
